Método
Reglas que aplica la calculadora
  • Jacobi arma el vector nuevo solo con la iteración anterior.
  • Gauss-Seidel usa cada componente en cuanto la calcula.
  • El paro es ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖∞ < tolerancia.
  • El redondeo es a las cifras pedidas, con el empate alejándose de cero.
  • Hay convergencia para cualquier x⁰ si A es estrictamente diagonal dominante o si ρ(T) < 1.
  • TJ = −D⁻¹(L + U) y TG = −(D + L)⁻¹U.
